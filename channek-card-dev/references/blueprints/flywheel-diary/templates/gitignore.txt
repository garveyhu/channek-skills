# 频道 .gitignore 模板
#
# 频道要不要进 git？——要。卡是资产、内容是心血，但**重媒体不进**。
# 判据一句话：**能重新渲染出来的，不入库；重新做一遍要花钱花时间的，入库。**
#
# 入库：代码 / 文本 / json + 卡的可分发小资产（片头片尾、音效、定妆图、字体、音色档）
# 不入库：内容私有重媒体（母片 / 配音 / 抽帧——可重渲）+ 超大素材帧序列（本机另备份）
#
# 用法：把 <> 里的占位换成你卡的实际目录名（这些名字由卡的 layout 决定，不是常量）。

# ── 构建 / 缓存 ──────────────────────────────────────────────
node_modules/
out/
dist/
.cache/
__pycache__/
*.pyc

# 例外：插件包的 dist 是 checked-in 的可装产物（沙箱只认包内文件·必须免构建可装）
!plugins/**/dist/
!plugins/**/dist/**

# ── 内容私有重媒体：成片 / 抽帧 / 配音 / 分发成品 ──────────────
# 体积大、可重渲、本机保留即可
**/<母版目录>/*.mp4
**/<母版目录>/*.mov
**/<母版目录>/*.webm
**/<母版目录>/*.png
**/<分发目录>/*.mp4
**/<分发目录>/*.mov
**/<配音目录>/*.wav
**/<配音目录>/*.mp3
# 子目录同样是重媒体——上面两条只挡直接子文件
**/<配音目录>/**/*.wav
**/<配音目录>/**/*.mp3
**/_帧-*

# ── 超大素材库：IP 动作帧序列等（几百 MB 起·本机另备份）────────
**/<动作库目录>/

# ── 本地索引（含绝对路径·可重建）─────────────────────────────
**/.asset-index/

# ── 发布配置：白名单式——只收 .md，凭据 / token / cookie 绝不入库 ──
# 这一段是安全边界，不是洁癖。先全挡、再逐条放行。
**/<发布配置目录>/**
!**/<发布配置目录>/**/
!**/<发布配置目录>/**/*.md

# ── 系统 / 敏感 ─────────────────────────────────────────────
.DS_Store

# ── 运行时状态：机器生成、可重建 ──────────────────────────────
state.json

.channek/local/
.claude/

# ── 中间产物目录（返工保险·可重渲·clean 可清）──────────────────
**/<中间产物目录>/

# ── 保留空目录占位 ───────────────────────────────────────────
!**/.gitkeep

# ══════════════════════════════════════════════════════════════
# 三条容易做反的
# ══════════════════════════════════════════════════════════════
#
# 1. `.channek/local/` 必须挡：里面有 capabilities 快照、本机 publish 配置、skill 挂载
#    记录，全是这台机器的事实，进库会在别人机器上误导。
#    但 `.channek/workspace.json` / `plugins.json` / `settings.json` **要入库**——
#    那是频道身份与启用清单。
#
# 2. `.claude/` 挡掉：里面全是软链，指向本机的插件目录与卡目录。软链进库在别人机器上
#    就是一堆断链。真身在卡的 `skills/` 里，那个才入库。
#
# 3. 目录名不是常量：`母版` / `配音` / `分发` 这些名字来自**你卡的 layout 声明**。
#    换一张卡它们就变。写 .gitignore 前先 `channek card layout.artifacts` 看一眼。
